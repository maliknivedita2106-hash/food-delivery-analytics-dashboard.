# Food Delivery Analytics Dashboard
An Excel dashboard project analyzing food delivery performance, sales, and order trends.
## Project Overview
This project presents an interactive Food Delivery Analytics Dashboard created using Microsoft Excel to analyze food delivery performance and business trends.

## Tools Used
- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers
- Data Visualization

## Project Objectives
- Analyze food delivery order performance.
- Track key business performance indicators.
- Identify trends in orders and revenue.
- Present data through an interactive dashboard.

## Key Skills
- Data Analysis
- Data Visualization
- Dashboard Design
- Excel Reporting

## Project File
- Food_Delivery_Dashboard_Dataset_Project (Excel).xlsx

## Conclusion
This project demonstrates how Microsoft Excel can be used to organize data, analyze business performance, and present insights through an interactive dashboard.
